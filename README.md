## 🧠 Sobre o Projeto

O Chama o Dev é um site desenvolvido para apresentar serviços de tecnologia, equipe e empresas parceiras/clientes de uma consultoria de software.

O objetivo principal é transmitir profissionalismo, confiança e inovação, utilizando um design moderno com elementos visuais tecnológicos.


## ✨ Funcionalidades

🖥️ Página inicial com destaque (hero section)

📊 Exibição de empresas clientes e parceiras

🧩 Cards de serviços oferecidos

👨‍💻 Seção de equipe com perfis profissionais

📞 Botões de chamada para ação (CTA)

🔗 Links para contato e redes profissionais


## 🛠️ Tecnologias Utilizadas

HTML5

CSS3

Design responsivo

Flexbox 


## 🎨 Design

O layout segue um padrão moderno com:

Tema escuro (dark mode)

Destaques em azul/ciano

Elementos futuristas (IA/robô)

Interface limpa e intuitiva


## 🚀 Como Rodar o Projeto

Acesse a pasta:

index.html
